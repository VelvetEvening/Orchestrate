# 浅色工作台开发与验收

分支：`design/light-workspace`。用户已认可浅灰、白色内容区和少量雾蓝的示意方向，四大模块及设置同等重要。本分支为本地验收候选，不代表已发布。

## Direction contract

- THESIS：让内容和日常操作清楚、安静；消除侧栏、标题栏和运行输出的大面积深色，统一所有原生窗口。
- OWN-WORLD：浅灰桌面底、白色工作面、雾蓝选择和主操作，深灰文字。统一线性图标、小圆角、细边界与紧凑控件；不引入装饰动画或大型背景效果。
- STORY：用户通过稳定导航进入四大模块，查找与选择内容，阅读或编辑，然后获得明确且不过度打断的反馈。
- FIRST VIEWPORT：浅色左导航，右侧紧凑页标题；各模块沿用适合其内容的日历、列表/详情和树形组织，主操作清楚可见，正文保留可用面积。
- FORM：用户已确认的浅色原生工作台方向；以聊天中的交互示意为色彩和控件参考，真实功能、月历、独立窗口与数据语义以现有 Qt 应用为准。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验收范围

- 主窗口、展开/收起导航、四大模块与设置；列表选择、键盘焦点、拖动目标、右键菜单和工具提示。
- 日记、提醒、日记集合、项目设置、大纲、协作记录、剪贴板编辑与工具参数窗口。
- 阅读/编辑、保存与错误、空内容和搜索无结果、工具运行输出与状态。
- 默认窗口、最小可用窗口、中文长标题、文本缩放与公式预览。

## 数据与发布边界

回归与截图使用测试目录和合成记录，不写入正式安装的数据。验收通过后再决定发布版本与发布流程。

## 已实现

- 在 `app/src/ui/` 与 `app/resources/ui/` 集中管理调色板、Qt 样式和线性图标。主窗口及独立窗口共用浅色标题栏、控件、菜单、选中态与焦点反馈。
- 四大模块、设置、预览/编辑页签、参数表单及运行输出同步调整。日历用形状和文字区分日记、提醒及日期状态，保留原有月历操作。
- 项目大纲改为单击按钮打开，支持 Enter / Space；大纲显示自动保存状态，协作记录显示保存结果。剪贴板、项目和提醒的空内容提示不占用数据行。
- 自动化详情中的长标题允许换行和收缩；最小 980×640 窗口不产生隐藏的横向溢出。工具输出继续遵守原有 UTF-8 连续解码约定。

## 本地验收

候选版本号为 `3.2.0`。构建产物仍位于唯一开发目录 `app/build-qt/`；其中 `visual-review-preview/Orchestrate.exe` 是本轮独立验收副本，包含合成日记、项目、剪贴板和只读示例工具。该副本关闭自动更新、全局快捷键与剪贴板监听，避免与正式安装相互影响。

建议依次体验四大模块和设置，查看独立窗口、折叠导航、搜索、保存反馈与 980×640 最小窗口。示例工具只输出文本；实际业务数据和外部工具接入可在验收方向确认后进一步检查。

截图与测试脚本遵循仓库约定，仅保留在本地忽略目录；未创建发布包、Git 标签或线上 Release。

### 本轮验证结果（2026-11-11）

完整构建通过；以下 10 组相关回归全部通过（54.69 秒）：`database_migration`、`database_schema`、`math_preview`、`release_info`、`update_checker`、`automation_contract`、`builtin_acceptance`、`heading_text`、`clipboard`、`startup_visibility`。其中新增窄窗口详情宽度、中文成功输出、启动失败与浅色输出区检查。

独立视觉评审抽查九张原生界面截图及相关代码，发现自动化窄窗口裁切和验收输出样例编码不符合合同两项问题。修复后补拍默认窗口及两张紧凑窗口截图，复评两项均为 `resolved`，处置为 `ship`；该复评结论仅覆盖这两项修复。本地候选完成，不等同于用户验收或正式发布。
