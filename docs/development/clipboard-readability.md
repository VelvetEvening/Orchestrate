# v3.6.1 剪贴板阅读与编辑导航

开发分支：`feat/v3.6.1-clipboard-readability`。用户于 2026-11-14 验收并授权合入 main、推送和发布 v3.6.1。

- 剪贴板列表、内容预览及编辑正文从 10pt 调整为 18pt，放大 1.8 倍；沿用 Microsoft YaHei UI。列表取消固定 40px 行高，按字体和内边距自动适配，本机实测为 50px。
- 顶部标签页采用 11pt、灰白底、细边框和 6px 圆角；相邻标签叠压 8px，未选中标签下沉 4px，选中标签由 Qt 最后绘制而覆盖相邻边缘，显示雾蓝底；键盘焦点有独立描边。长标签省略，标签过多时保留名称宽度并横向滚动，历史星标、排序和拖动归类沿用。
- 日记、提醒、协作记录的即时／源码编辑及剪贴板编辑，在第一个视觉行按 ↑ 移到全文开头，在最后一个视觉行按 ↓ 移到全文末尾；Shift+↑/↓ 选择到对应边界。仍有上一／下一视觉行时正常移动，Ctrl／Alt／Meta 组合键沿用原生行为，不插入空行或改动文本。
- 数据库保持 schema v9，存储、复制格式及后台任务不变。

## 2026-11-14 验证

Release 开发构建通过，程序与 Windows 文件版本均为 3.6.1。首轮最终 `clipboard`、`workspace_navigation`、`markdown_edit`、`startup_visibility` 四个 CTest 套件全部通过（14.49 秒）；剪贴板为 22 passed，Markdown 编辑为 13 passed，原生启动为 4 passed。

检查普通 1180×760、紧凑 980×640、编辑页面及八标签／长标签截图。列表、预览和编辑正文实际字体均为 18pt，页签高 40px。首轮发现多标签被压得过窄，已修复并通过第二轮截图确认。

新增键盘回归覆盖即时编辑、源码和普通文本编辑：最后一行、自动换行、正常下移、Shift 选择、末尾空行、空内容、到末尾继续输入及撤销。原有保存、导航、排序、拖动归类和复制流程回归通过。

测试和截图仅保留在本地忽略目录 `app/tests`、`app/build-qt/tests/clipboard-test/artifacts`，使用独立合成数据；本轮未重新验收真实中文输入法和多显示器 DPI。

前一轮独立复核结合源代码和五张截图，结论为可交付开发版，未发现有证据的阻断问题；本轮不再扩大检查范围。

## 标签叠压与双向边界更新

按后续反馈将标签改为相连叠压，活动页签浮在前层；补齐 ↑ 到文首及 Shift+↑ 选择。开发构建通过，受影响的 `clipboard` 与 `markdown_edit` 两套回归通过（6.37 秒），分别为 22 passed 与 13 passed。复核普通窗口、八标签首尾滚动及长标签截图，页签整体高度仍为 40px。新增验证覆盖普通／源码／即时编辑的向上移动、自动换行、Shift 选择、到开头输入和撤销。
