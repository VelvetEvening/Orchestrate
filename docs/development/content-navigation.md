# v3.4.0 内容导航与窗口收纳

开发分支：`feat/v3.4.0-window-navigation`，从 v3.3.0 的 `3c97823` 创建。

## 使用规则

- Git 历史、提交详情、日记集合、日记、提醒、协作记录与剪贴板编辑默认在主窗口内容区打开。模块侧栏与全局窗口操作栏保持可用。
- 内容上方的“返回”（Alt+左箭头）回到来源页面，保留筛选、选择、阅读位置与编辑草稿。切换模块也保留当前内容。再次打开同一条目复用原页面。主窗口的快捷返回只操作当前嵌入内容，在模块根页无操作，不改变独立窗口中的页面。
- “关闭”或 Esc 释放当前内容；有未保存修改时，可保存、放弃修改或继续编辑。关闭父级内容时也检查其保留的子页面；保存失败留住草稿。退出程序、安装更新采用相同检查，隐藏到托盘不关闭内容。
- “独立打开”将当前内容和其下级页面移动到原生非模态窗口；在这个窗口内深入详情仍采用页面切换。点击“收回主窗口”将同一实例放回所属模块，并恢复模块选中状态。没有第二份编辑草稿。
- 独立窗口的关闭按钮关闭该窗口内的内容；若仅需放回主窗口，使用“收回主窗口”。未保存的草稿只在本次运行内保留，不承诺崩溃恢复或重启自动恢复。
- 日记、提醒、协作记录保存后留在原位阅读；剪贴板保存后留在当前编辑页。新建内容首次保存后使用正式记录标识，重新打开不会重复创建。
- 项目设置、目录选择、工具参数等短表单及删除确认保留原生对话框。删除规则、项目精确文字确认、工具运行和剪贴板双击复制后收起行为沿用。

## 实现边界

`ui/contentworkspace` 为时序记录、项目记录和剪贴板提供统一容器。内容仍使用现有 Qt 控件；以 `Qt::Widget` 嵌入，独立打开时移动整个内容面，保留编辑器文档、撤销栈、字号与选中位置。没有浏览器、轮询、常驻辅助进程或新的第三方依赖。

每个模块按内容标识登记页面，保存后更新新建草稿的标识。页面保留来源关系；父级关闭时先处理子页面。独立窗口拥有该分支的页面栈，而不是再为每一级创建原生窗口。返回与关闭分开，避免只为保留草稿而阻止模块切换。

Git 读取逻辑、只读约束和取消机制不变。返回或切换模块保留本次结果，显式关闭内容结束读取并释放结果；没有持久化 Git 缓存。重新绑定目录关闭旧 Git 内容，删除项目关闭所属内容。分支与标签仍分开，双击或 Enter 才打开提交详情。

剪贴板可保留多份编辑内容，自动历史清理跳过所有仍在编辑的已有条目；关闭后解除保护，手动保存仍解除自动清理资格。保存已有条目时读取当前分类，避免在返回列表并拖动归类后，保存草稿又把条目移回旧位置。

数据库维持 **schema v8**。日记插入接口增加返回新 ID 的能力；没有结构迁移。v3.3.0 以前的升级、备份与降级规则沿用。

## 设计系统继承

本次是既有 Windows Qt Widgets 工作台的导航扩展，保留 `DESIGN.md` 与 `.impeccable/design.json`。`ContentWorkspace` 使用现有白色 `content` 工作面，外层边距与间距为 0；内容操作行使用已有 `quiet` 按钮、线性返回图标和继承字体，内边距为左右 16、上下 8，按钮间距为 10。内容操作行位于工作面内，全局窗口操作栏与模块导航保持原职责。

核对依据为 `app/src/ui/theme.h`、`theme.cpp`、`app/resources/ui/light.qss` 及接入页面：灰白表面、雾蓝选择、Microsoft YaHei UI 的 10pt 正文及 Qt 字体回退沿用原值；保存与错误使用已有语义角色。独立内容由统一非模态容器承载，默认 1100×760、最小 720×520（Qt 逻辑尺寸），继续使用系统窗口层级与浅色标题栏。没有新增全局颜色、字体、圆角、投影、动画或分发栅格素材。
