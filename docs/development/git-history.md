# v3.3.0 项目 Git 历史

## 确定的范围

依据“v3.3.0 设计”中的最终决定，项目页原大纲入口替换为“Git 历史”。移除大纲窗口和专用数据，不将旧大纲转为协作记录。项目仍可不绑定目录，也可绑定普通目录。

每个项目可绑定本地 Windows、WSL 或 SSH 目录。WSL 自动发现发行版并读取所选发行版的默认用户；SSH 复用自动化工具的静态配置解析器，只列出默认配置直接声明的 Host，并显示用户提示。用户留空时采用目标环境的默认用户，验证成功后保存实际用户名和规范目录。Linux 路径支持绝对路径及 `~/`；不会创建账号。

独立窗口允许主页面继续操作，可最大化，历史列表独占主要区域。同一项目复用打开的窗口；切换项目不会切换已打开窗口的内容。重新绑定目录会关闭该项目旧窗口，下次读取新绑定。

## 读取与显示

- **提交历史**：默认包含绑定仓库已知的本地分支、远端跟踪分支、标签和 HEAD；分支和标签使用各自的下拉框，选择其中一项时清除另一项；也可选择当前 HEAD。每批 200 条，按拓扑顺序排列。刷新固定本次引用的提交编号，再通过标准输入传给 `git log`；继续加载沿用同一批编号，避免仓库新增提交造成分页重复或遗漏。查找作用于已加载提交的说明、作者、编号和引用，定位行而不隐藏图上的中间提交。
- **提交详情**：双击提交或在列表按 Enter 后打开非模态详情窗口；单击和查找只定位行，不读取详情。每个历史窗口最多复用一个详情窗口，详情固定到明确打开的提交，直到再次双击另一条提交；关闭历史窗口会同时关闭其详情。展示完整提交说明、作者、时间和编号；变更文件按需读取，选中文件后才加载 Diff。首次提交与空树比较；合并提交默认与第一个父提交比较，可切换其他父提交。支持重命名及二进制变更提示，Diff 使用原生只读文本和增删行配色。
- **分支对比**：首次打开页签及手动刷新时，读取绑定仓库的本地分支并通过 `git ls-remote --heads --refs` 查询所选远端。按同名分支的完整对象编号判断“仅本地存在／仅远端存在／一致／不一致”。不推算领先、落后或代码差别。默认只看差异，可搜索、显示全部；无分支数量及输出字节截断。
- **失败与空状态**：普通目录、空仓库、缺失 Git、认证失败、超时、内容过大分别显示可重试反馈；刷新失败保留当前窗口的上次成功内容。成功时只显示“读取成功”，不显示读取数量或时间；还有历史可读时显示“继续加载”，完整读取后隐藏按钮。没有配置远端时显示明确空状态。Git 需要在对应执行环境安装并位于 PATH 中。

窗口关闭时终止读取并释放结果；没有后台轮询或持久化 Git 仓库缓存。远端查询使用所在环境已有的认证，不弹出交互式登录窗口。私有远端的认证应事先在该环境配置好。

## 实现边界

`OrchestrateGit` 是独立 Qt Widgets 库。`gitreader` 统一命令、解析和取消；`githistorywindow` 实现原生表格与自行实现的提交图，`gitcommitdialog` 按需展示提交详情；`repositorybinding` 处理环境选择与验证。复用现有 WSL、SSH 和 POSIX 引号封装，没有引入 libgit2、浏览器、常驻服务或第三方绘图源码。

只运行读取类 Git 命令，不执行 fetch、pull、checkout、reset 或写入引用。禁用可选锁、隐式延迟获取、交互式认证、外部 Diff 与 textconv；清理继承的 Git 仓库选择环境变量。用户输入通过 argv 或 POSIX 单引号传递，路径使用字面 pathspec，文件名中的通配符和前导选项不参与解释。读取进程不显示控制台窗口；Windows Job Object 用于窗口取消时回收本机子进程。

每个读取有 30 秒超时。提交元数据、详情和文件列表有 16 MiB 单次输出保护；单文件 Diff 为 4 MiB，超限明确停止，不把截断结果当作完整内容。引用和分支对比不使用这项上限。标准错误最多保留 64 KiB。

数据库由 schema v7 升至 v8：增加 `projects.target_type / target_name / target_user`，旧目录默认本地；删除 `projects.outline` 及大纲专用偏好。迁移前沿用 `VACUUM INTO` 一致备份，事务失败整体回滚。项目、协作记录、文件夹、剪贴板及其他内容保持原值；没有生成额外协作记录。回退 v3.2.2 时同时恢复 schema v7 数据库备份。

参考的 Git 官方命令约定：[log](https://git-scm.com/docs/git-log)、[diff-tree](https://git-scm.com/docs/git-diff-tree)、[ls-remote](https://git-scm.com/docs/git-ls-remote)。

## 验证方式

本地测试按仓库约定放在忽略的 `app/tests/`，构建与产物均使用 `app/build-qt`。`GitHistoryTest` 使用随机临时仓库、合成 SQLite、Qt offscreen、模拟 SSH 传输及 Git Bash 的真实 POSIX 引号解析，不访问真实 SSH 服务器或用户仓库。截图位于 `app/build-qt/tests/git-history-test/`。

2026-11-12 验证结果：应用与全部本地测试目标构建成功；`ctest --test-dir app/build-qt --output-on-failure -E '^startup_visibility$'` **22/22 通过**。新增 Git 套件为 **11 passed / 0 failed**（含初始化与清理），覆盖拓扑分页、根提交／合并／重命名／二进制 Diff、仓库子目录和字面路径、四种分支状态、空远端、超过 1 MiB 的 18,000 分支完整读取、失败保留、关闭取消、模拟 SSH 引号与标准输入、环境绑定持久化和窗口固定项目。只读用例比较读取前后的完整仓库文件哈希，没有改变仓库文件。

合成 v7 数据库升级后为 v8，项目表无 `outline` 列，原协作记录保留；迁移快照仍为 v7，并保留升级前的大纲原值。离屏截图已检查默认和紧凑窗口、提交详情、分支对比和目录绑定。简化界面后的 22 项回归仍全部通过；Git 用例补充了独立分支／标签切换、单击不打开详情、双击／Enter 打开与复用详情、详情保持原提交、关闭历史时同时销毁详情的验证。

2026-11-12 在用户授权下，使用原生验收窗口只读访问当前 Orchestrate 仓库，确认分支／标签分别筛选、单击只选中、双击打开说明和 Diff、关闭详情后保留原选择，以及实时查询 origin 后显示简洁读取状态。验收窗口已关闭。该检查不启动日用版，不读写日用数据库；自动化测试与原生界面检查分别记录，不将模拟 SSH 视为真实 SSH 认证验收。

用户已授权本轮原生界面检查；WSL 资源管理器和实际 SSH 认证仍依赖对应环境，可按下列步骤现场确认：

1. 为测试项目绑定本地仓库，点击“Git 历史”，查看提交图，双击提交后查看详情及文件 Diff；切换项目后旧窗口应保留，重复点击同一项目应唤回已有窗口。
2. 在“分支对比”选择远端，切换“只看差异”、搜索和刷新，核对四种状态；断网后刷新应显示错误并保留上次结果。
3. 若使用 WSL／SSH，为测试项目设置对应环境并粘贴目录，确认默认用户、保存后的实际用户、历史读取及目录双击行为。

开发阶段不会启动或迁移日用版 `E:\Tools\Mytools\orchestrate`。原生窗口可见性测试 `startup_visibility` 需要实际显示窗口，本轮命令行回归排除该项。
