# v3.5.0 Qt 原生即时编辑

## 范围与交互

v3.5.5 更新：协作记录取消只读阅读模式，打开即可即时编辑，Ctrl+S 保存后继续编辑；正文默认 20pt，摘要默认 24pt。使用 `text_zoom.work_record.v2` 和 `text_zoom.work_record_summary.v2` 独立记住本次字号调整，旧字号偏好保留但不覆盖新默认值。v3.5.6 将直接编辑扩展到日记与提醒，默认 20pt，分别以 `text_zoom.diary.v2`、`text_zoom.reminder.v2` 持久化，移除模式切换。离开保护见[内容导航说明](content-navigation.md)。

日记、提醒说明、协作记录正文和摘要继续共用 `HeadingTextEdit`。所有记录打开后在同一区域直接修改：当前段落显示可修改的 Markdown 语法，离开后排版；其他段落的标题、公式和表格持续显示。当前标题仍采用标题字号。默认直接点击已渲染的段落、公式或单元格进行修改，无需切换整篇源码。整篇源码入口保留在右键菜单“编辑整篇 Markdown 源码”，源码视图右键提供“返回即时编辑”；不再显示常驻源码按钮，包括隐藏内部预览／编辑标签的协作记录页。

支持一至六级 ATX 标题、加粗、斜体、删除线、行内代码、围栏及缩进代码、基本有序／无序列表、引用、分隔线、文字链接、GFM 管道表格和原有四种公式分隔符。代码内容按字面显示；HTML、外部图片、复杂嵌套与扩展语法不执行、不加载外部资源，也不作为完整 CommonMark 支持作承诺。列表条目与悬停提示仍沿用原有轻量显示。

表格保留表头、列对齐和单元格内的文字格式及公式。点击单元格后只展开当前单元格的语法，Tab／Shift+Tab 移到相邻单元格，最后一格 Tab 新增一行。右键提供插入／删除行列；表头不能直接删除，最后一列不能删除。宽内容由原生水平滚动承载。直接修改 `|` 或多行粘贴会按新的 Markdown 原文重新解析；可通过源码入口整理任意结构。行列操作只重新组织当前表格的管道与空白，不改写其他段落。

## 数据与撤销

原文 `QPlainTextEdit` 文档是保存与撤销的唯一依据。即时视图通过 UTF-16 偏移映射到原文，编辑应用到对应源区间，不把富文本反向序列化成 Markdown。切换阅读、即时编辑、源码或字号不写入保存内容，也不清空撤销栈。复制全篇得到完整 Markdown；公式始终复制为 LaTeX。粘贴只接收纯文本。正文内拖放暂不启用，避免跨隐藏语法移动时丢失原文，可用剪切／粘贴完成移动。

输入法预编辑不写入原文或撤销栈；提交才替换原文，异步排版等待组合输入提交或取消。真实 Windows 中文输入法候选窗口与鼠标选择已在隔离开发版中检查；多屏和不同 DPI 行为不在此次覆盖范围。

数据库保持 schema v8，不新增迁移。原有页面负责保存失败、关闭草稿和未修改字段的 CRLF 保真。

## 实现与资源

- `markdowntext.*`：把原文分为段落、公式、代码和表格块，生成 Qt 文档片段及源偏移映射；未知内容保留文字。
- `markdownedit.*`：处理编辑、选择、输入法、原文撤销和表格操作，复用未变化的文档片段，只替换发生变化的区间。每次修改会扫描源文本来识别受影响结构，不宣称已实现增量语法解析。
- `mathpreview.*`：同字号且公式集合不变时复用结果，不因正文输入重启工作进程；公式改变时保留其余公式的缓存。失败结果在公式或字号改变前不重复尝试。进程超时、内存、数量和输出限制沿用已有保护，无常驻浏览器或网络依赖。
- `HeadingTextEdit` 保留已有公开接口及预览模式信号，各内容页无需重新实现保存逻辑。
