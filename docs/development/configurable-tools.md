# 可配置工具与命令（v3.6.0）

## 用户流程

“自动化工具”只保留“接入工具”一个注册按钮。同一窗口的“接入方式”可选“工具目录”或“JSON 配置文件”，“执行环境”可选本地 Windows、WSL 或 SSH。WSL/SSH 另填主机或发行版和登录用户，路径使用目标环境的绝对路径或 `~/`；用户留空时读取默认身份，成功后保存实际用户名和规范路径，后续不会随环境默认用户变化而改用其他账号。

目录模式优先读取 `orchestrate-tool.json`，没有声明时扫描入口并在目标环境读取帮助。JSON 模式直接选择本地 `.json` 文件或填写远端文件路径，文件名不限；先读取父目录确认身份和路径，再用现有 v1 解析器读取指定配置。配置优先，不自动改写其参数；错误会清空旧列表并禁止接入，可修正后重新读取。重复导入沿用替换预览。

声明和状态文件均非必需；没有状态文件时隐藏状态区，也不会触发状态读取。注册菜单和单独手动添加工具入口已移除，已有工具的“工具设置…”与手动命令编辑仍保留，可修改名称、说明、工作目录、状态文件和环境变量。标准最小 JSON 及字段见[接入指南第 4 节](../automation-tool-contract-v1.md#4-声明字段完整约定)。

选择工具后可添加命令，右键命令可编辑、停用、启用或删除。拖动命令行或按 Ctrl+↑/↓ 保存顺序。命令配置包含程序、独立参数项和运行方式；可以粘贴现成命令读取程序与参数。粘贴入口只拆分参数，不执行管道、重定向或变量展开；脚本需要明确解释器。

命令名称下直接显示已有或从帮助中提取的单行简介，过长时省略号截断，悬停查看全文。空白简介不占额外一行，完整说明保留在工具提示和可访问描述中。

勾选“运行前填写参数”后，可添加文本、整数、小数、时间、开关、下拉、文件或目录参数，定义默认值和必填项。参数列表中勾选的项在运行窗口填写，未勾选的项使用默认值固定到命令中。没有运行参数时双击直接发起命令；高风险标记仍要求确认。下拉支持固定选项、文件或查询命令，并允许项目、账号等上游字段驱动区域、实例列表。查询失败时显示原因并阻止使用过期选项运行。

应用内执行捕获输出及退出码，适用于非交互任务。外部终端适用于菜单、问答及需要 Ctrl+C 的长任务，Orchestrate 只记录“已打开终端”；任务结束及业务结果在终端查看。

## 默认接入与自由调整

默认窗口显示接入方式、执行环境、目录／配置文件路径、一行说明及接入／取消操作，不常驻命令清单或长说明。默认加入全部声明命令，或读取入口和各子命令帮助，生成整组命令及参数配置；menu 作为其中一条保留。“自行挑选与调整…”按需展开命令清单；选项来源的详细提示放在悬停说明中。

展开后可勾选子集、查看参数并编辑，也可通过“添加命令…”直接手填，无需先成功读取帮助；目录模式还能改启动入口并读取命令与介绍。已有工具的“发现更多命令…”默认展开该模式。改接入方式、执行环境、主机、用户或路径会使旧结果失效；改启动入口立即清空旧命令、参数和帮助结果。新入口读取失败时显示原因，不会继续保存上个入口的命令。底部接入／取消操作保持可达。

CANNLab 默认接入 demo、menu、accounts、import、environments、start、reset-pending 共 7 条命令和可提取参数，工作目录为所选目录，并补齐 `PYTHONUTF8=1`。menu 与 start 使用外部终端，start 包含 account、resource、minutes、interval、jitter、poll、timeout、max_attempts 共 8 项参数。接入过程只读取目录和帮助，之后双击命令才发起执行；不改变 CANNLab 的 settings.json 或账号数据。

## 从目录发现命令

本地扫描读取根目录文件名、README、批处理入口以及少量配置数值，不递归扫描账户数据。优先使用目录中实际存在的 Python 模块，避免把 README 中的 pip/venv 安装示例当作启动入口；检测到已有 `.venv/Scripts/python.exe` 或 `venv/Scripts/python.exe` 时优先使用该解释器。也列出 Python、PowerShell 脚本和可执行程序。默认接入会读取所选入口和各命令的 `--help`；展开后可主动读取、挑选并进入命令编辑器核对。

WSL/SSH 通过固定只读 POSIX 脚本读取同类目录信息、声明和实际用户，不依赖 Python 完成扫描，也不创建或修改远端文件。路径作为独立参数传递，支持空格、中文和单引号。扫描以目标环境的 `python3` 为优先系统入口，缺少时回退到 `python`；已有 `.venv/bin/python` 或 `venv/bin/python` 优先。远端同时可发现 shell 脚本和无扩展名的可执行入口。目录扫描异步进行，30 秒超时，数据上限 1 MiB；帮助仍由目标环境中的工具解释器执行，需自行准备运行依赖。

帮助解析是规则提取：主要覆盖 argparse 风格的子命令表、长选项、枚举、简单互斥组。不会完整理解任意 CLI、复杂位置参数、短选项别名或所有嵌套子命令。没有读到的字段可以手动补充。CANNLab 的 settings.json 数值可用作默认值，执行方式可在编辑器调整。帮助命令本身由第三方程序处理，是否遵守只展示帮助取决于该工具。

### 通用动态下拉发现与设置

无声明时，默认接入和高级选取都会读取相关列表查询的帮助，再按明确的 list／列出／查询列表说明与参数关系匹配来源。仅在唯一匹配且依赖可用时，把文本参数转为 `choice` 并生成 `options_source`，格式为自动识别；查询的必填参数可引用同一表单的上游字段。这套规则适用于不同工具，不按 CANNLab 等工具名称硬编码。明显操作命令、交互命令和已标记的高风险命令不会成为自动来源；歧义保留原字段。用户显式编辑的命令和声明配置优先。

接入仍只读取目录和帮助，不执行真实选项查询。打开运行表单、刷新或“测试读取”时，才按配置读取工具实际输出。自动格式支持最多四层对象路径中的唯一 JSON 数组、常见值／显示字段、简单逐行列表和带可识别列名的竖线／制表符表格。多个列表、未知字段或无列名表格需要明确映射，不猜实际 ID 所在列。

在参数编辑器中设置“读取文件或查询命令”来源，可从“工具已有查询”选命令，输出格式默认“自动识别”。运行表单的来源下拉旁也可点“设置下拉”，测试时使用当前项目、账号等上游值。无列名表格会在“测试读取”后展示预览；用两个下拉选择实际参数值和显示文字所在列，保存一次后复用，运行表单中的修改会写回命令配置。上游变化会清空旧下游并重新读取。

CANNLab 的 account／resource 参数可由同一规则关联 accounts／environments 查询；实际列表仍取决于工具输出。实例文本可能截断，选列不能恢复缺失的 ID，带省略标记的文本值会被拒绝。工具应提供完整值，优先提供稳定的 JSON value/label 列表。README 用于说明入口、参数、查询依赖和真实输出，`--help` 应同步；精确关联可写入现有 v1 声明。工具作者清单及通用示例见[接入指南第 13 节](../automation-tool-contract-v1.md#13-每个工具-readme-应写什么)。

## 数据与执行边界

数据库 schema v9 增加工具 `customized`、`environment`，命令 `enabled`、`position`。编辑保存使用工具与命令的完整事务快照，保留现有命令 ID。旧命令默认启用，初始排序沿用 ID。迁移前仍创建 SQLite 一致备份。

手动修改工具信息、命令或顺序会标记为自定义。内置同步保留该快照；便携目录搬迁时修正原内置目录内的工作目录、状态路径及命令路径。无声明的同一执行目标、同目录重复接入会追加缺失命令，按程序与参数识别重复，并为匹配命令补齐空白简介；仅将与当前帮助原始推断完全相同的参数升级为发现的动态下拉，保留已调整字段。非空的自定义说明及已有名称、ID、启停和顺序保持不变，menu 继续保留。“发现更多命令…”也追加命令。声明重复导入、恢复默认和重新读取声明则先显示当前/声明配置，默认保留当前；确认后整套替换，分组和内置身份保留。接入声明继续使用 `orchestrate-tool/v1`，状态继续使用 `orchestrate-state/v1`。

公共执行构造器负责 Windows、WSL、SSH 的程序与参数传递，动态选项查询沿用同一执行环境、工作目录和认证，不新增外部认证服务。用户值不作为隐式 shell 文本执行。Windows 外部终端使用独立 PowerShell 控制台及 ProcessStartInfo 保留空参数、引号、中文和反斜杠；WSL 通过 `--exec`，SSH 逐项 POSIX 引用。工具环境变量只覆盖目标命令。状态、文件和帮助读取异步并设上限；外部选项查询随依赖变化刷新，不做轮询。

主要实现：`automationpage.cpp` 负责流程与持久化，`tooleditor.h`/`discoverydialog.h` 提供编辑器，`tooldirectory.h` 统一目录读取，`clidiscovery.h` 提取草稿，`optionsdiscovery.h` 匹配下拉来源，`commandform.h` 负责运行参数与联动，`optionsformat.h`/`optionssource.h` 识别和读取选项，`commandlaunch.h` 统一启动。
