# 使用、数据与更新

## 安装与启动

下载 Windows x64 便携包，完整解压到可写目录，运行 `Orchestrate.exe`。Qt 运行库和离线公式组件随包提供。[正式版下载页](https://github.com/VelvetEvening/Orchestrate/releases/latest)

通过工具页的“接入工具”选择目录或 JSON 声明。WSL、SSH 和外部工具的运行环境需自行准备。[工具接入协议](automation-tool-contract-v1.md)

## 编辑记录

`Ctrl+S` 保存，`Ctrl+滚轮` 调整阅读字号。点击“独立打开”或“收回主窗口”可移动当前内容并保留草稿。离开有未保存修改的记录时，可选择保存、放弃修改或继续编辑。

## 数据在哪里

| 内容 | 位置 |
| --- | --- |
| 日记、提醒、项目、协作记录、剪贴板及工作台偏好 | 程序旁的 `data/orchestrate.sqlite3` |
| 数据库升级前的快照 | `data/backups/` |
| 已下载的皮肤与侧栏插画 | `data/skins/` |
| 自动检查更新偏好与缓存 | `data/update-check.json` |
| 开机启动 | 当前 Windows 用户的启动设置 |
| 内置工具状态 | `tools/<工具>/state/` |
| 外部工具的数据与凭证 | 由外部工具自行保存 |

备份前从托盘完全退出，再复制整个 `data/`、工具状态及个人配置。剪贴板里的文件条目只保存路径，原文件需单独备份。

## 风格与布局

在“设置 → 风格与布局”分别选择风格和布局，旁边的预览随选择更新。每款主题都可搭配标准或紧凑布局。“界面动效”默认跟随 Windows 的动画效果。设为“关闭”后，侧栏收放与页面切换即时完成。

打开“主题库”可按名称搜索内置和扩展主题。在列表中下载扩展主题，再点击“启用”。当前主题显示“使用中”。选中主题后，也可按回车启用或下载，按 `Delete` 删除已安装的扩展主题。内置和已下载的主题可离线使用。[扩展主题目录](https://github.com/VelvetEvening/Orchestrate-skins)

删除正在使用的扩展主题，或从旧版“冷灰 × 墨蓝（紧凑）”升级，都会回到“云白 × 雾蓝”并保留原来的布局密度。

## 运行与托盘

关闭主窗口后默认留在托盘，从托盘菜单可完全退出。开机启动默认关闭。在“设置 → 运行与托盘”可调整开机启动、驻留托盘和全局快捷键。若 Windows 禁用了启动项，可从该行打开系统的启动应用设置。

全局快捷键默认是 `Alt+X`，可唤起或收起主窗口。选择 `Alt` 或 `Ctrl`，输入一个 A–Z 字母，开启时立即生效，关闭时保存供下次使用。同时运行多个副本时，每个副本需使用不同组合。

## 剪贴板

监听默认关闭。要自动记录，在“剪贴板 → 设置”勾选“监听剪贴板”。工作区较宽时列表与预览并排显示，较窄时上下显示。

- **重复复制**　在“历史”顶层优先复用完全相同的手动条目，保留其位置。匹配到自动条目则置顶。没有完整匹配且首条是自动记录时，才按正文合并。纯文本可与同文的富文本或图片合并，两份同文富文本保留最新格式。不同图片分别保留，正在编辑的内容和其他收藏位置受保护。
- **记录范围**　跳过纯空白文本和带历史排除标记的内容。数量上限只清理“历史”顶层的自动条目。旧条目都在编辑时先保留新内容，下次新增时再清理。
- **取用**　双击或按回车复制并收起窗口，取用的自动历史条目会置顶。在“剪贴板 → 设置”可开启“取用后粘贴到上一个窗口”。无法自动粘贴时可手动粘贴。
- **编辑**　纯文本和富文本可直接编辑。富文本只改标题会保留格式，修改正文并保存会转为纯文本。图片和文件可修改标题，附带文字可另存为纯文本。

## 更新与移动

在“设置 → 版本与更新”检查并安装正式版本。自动检查可关闭，不自动下载安装。

更新前结束运行中的工具、关机倒计时及引用程序目录的计划任务。安装目录及其上级目录需可写。

更新器校验 ZIP 与文件清单，保留个人数据。新版启动失败时回滚。确认启动成功且相关计划任务恢复后，更新器清理本次临时文件和旧程序备份。失败时保留恢复材料。

数据库按需迁移至 schema 9，迁移前生成一致快照，失败回滚。降级时同时恢复对应程序和数据库，不能只替换 EXE。日常备份仍由用户安排。

搬迁前关闭旧目录的开机启动，完全退出后移动整包，再在新目录重新开启。全局快捷键设置跟随便携数据。定时关机任务由 Windows 管理，迁移后请在工具页核对状态。

## 内测版迁入

| 来源 | 方式 |
| --- | --- |
| v1.1.2 及以后 | 可从应用内直接升级，无需逐版安装。 |
| v1.1.0 / v1.1.1 | 首次升级仍由旧更新器执行：先手动停用引用程序目录的计划任务，完成后恢复。 |
| v1.0.0 | 完全退出并备份，完整解压新版，迁入旧 `data/`、工具状态和个人配置，保持原程序路径。 |

旧项目大纲不转换为协作记录；需要保留其内容时先从旧版导出或复制。其他已有数据由迁移逻辑处理。
