# 数据与更新

## 数据在哪里

| 内容 | 位置 |
| --- | --- |
| 日记、提醒、项目、协作记录、剪贴板及设置 | 程序旁的 `data/orchestrate.sqlite3` |
| 数据库升级前的快照 | `data/backups/` |
| 已下载的皮肤与侧栏插画 | `data/skins/` |
| 内置工具状态 | `tools/<工具>/state/` |
| 外部工具的数据与凭证 | 由外部工具自行保存 |

备份前从托盘完全退出，再复制整个 `data/`、工具状态及个人配置。剪贴板里的文件条目只保存路径，原文件需单独备份。

## 风格与布局

在“设置 → 风格与布局”中，“风格”用于选择皮肤，“布局”用于调整界面的疏密。打开“管理皮肤”后，可以按名称搜索，也可以点右上角的刷新图标获取最新目录。点击皮肤所在行的下载图标，出现勾号即表示已安装。点“返回”后即可在“风格”中切换，离线也能使用。

删除正在使用的皮肤，或从旧版“冷灰 × 墨蓝（紧凑）”升级，都会回到“云白 × 雾蓝”并保留原来的布局密度。

## 剪贴板

- **重复复制**　在“历史”顶层优先复用完全相同的手动条目，保留其位置。匹配到自动条目则置顶。没有完整匹配且首条是自动记录时，才按正文合并。纯文本可与同文的富文本或图片合并，两份同文富文本保留最新格式。不同图片分别保留，正在编辑的内容和其他收藏位置受保护。
- **记录范围**　跳过纯空白文本和带历史排除标记的内容。数量上限只清理“历史”顶层的自动条目。旧条目都在编辑时先保留新内容，下次新增时再清理。
- **取用**　双击或按回车复制并收起窗口，取用的自动历史条目会置顶。在“剪贴板 → 设置”可开启“取用后粘贴到上一个窗口”。无法自动粘贴时可手动粘贴。
- **编辑**　纯文本和富文本可直接编辑。富文本只改标题会保留格式，修改正文并保存会转为纯文本。图片和文件可修改标题，附带文字可另存为纯文本。

## 更新与移动

在“设置 → 版本与更新”检查并安装正式版本。自动检查可关闭，不自动下载安装。

更新器校验 ZIP 与文件清单，保留个人数据；新版启动失败时回滚。只有启动确认且相关计划任务恢复完成后，才清理本次临时文件和旧程序备份；失败时保留恢复材料。安装目录及其上级目录需可写，更新前结束运行中的工具和关机倒计时。

数据库按需迁移至 schema 9，迁移前生成一致快照，失败回滚。降级时同时恢复对应程序和数据库，不能只替换 EXE。日常备份仍由用户安排。

搬迁目录前关闭旧目录的开机自启，完全退出后移动整包，再在新目录重新开启。全局唤起快捷键随各目录的数据保存，默认是 `Alt+X`。在“设置 → 运行与托盘”中可以更换组合，开启时改键立即生效，关闭时也可以预设下次使用的组合。同时运行多个副本时，请分别选择不同组合。定时关机任务也是系统资源。

## 内测版迁入

| 来源 | 方式 |
| --- | --- |
| v1.1.2 及以后 | 可从应用内直接升级，无需逐版安装。 |
| v1.1.0 / v1.1.1 | 首次升级仍由旧更新器执行：先手动停用引用程序目录的计划任务，完成后恢复。 |
| v1.0.0 | 完全退出并备份，完整解压新版，迁入旧 `data/`、工具状态和个人配置，保持原程序路径。 |

旧项目大纲不转换为协作记录；需要保留其内容时先从旧版导出或复制。其他已有数据由迁移逻辑处理。
