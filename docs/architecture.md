# 架构与边界

C++17、Qt 6 Widgets、SQLite，面向 Windows x64。采用原生控件与按需子进程，不依赖浏览器内核或常驻渲染服务。

| 位置 | 职责 |
| --- | --- |
| `app/src/ui`、`widgets` | 主题、动效、内容工作区、Markdown 编辑和公式展示。 |
| `app/src/pages` | 日历、项目、工具、剪贴板及各内容页。 |
| `app/src/data` | 数据库连接、schema 迁移及日记／项目／工具／剪贴板仓储。 |
| `app/src/automation` | 声明解析、目录与帮助发现、参数表单、进程执行和状态读取。 |
| `app/src/git` | 只读仓库查询、路径处理、异步读取与取消。 |
| `app/src/update`、`app/updater` | 发布查询、下载校验、目录替换、重启确认与回滚。 |
| `app/src/platform` | Windows、托盘、自启、快捷键与本地文件访问。 |

## 关键约定

- SQLite 连接由 `AppDatabase` 持有，仓储共用事务；外部工具不直接操作客户端数据库。
- 工具身份是稳定 `id` 加执行目标；命令是配置，一次执行是“工具运行”，业务状态由工具的 JSON 快照提供。
- “协作记录”包含标题、摘要和正文；项目目录绑定不要求是 Git 仓库。
- 返回和模块切换保留内容实例，关闭才释放；异步结果不得访问已销毁对象或覆盖新选择。
- 主题库在首次打开或手动刷新时请求扩展主题目录。扩展主题由静态配色 JSON 和可选的侧栏 PNG 组成，安装前校验，启动时从本地读取。
- 工具状态按启动、选择、手动刷新和命令结束读取，不周期轮询；调度、凭证和跨进程业务锁归工具管理。
- Git 查询不执行 fetch、checkout、reset 等写入操作。外部命令按独立参数传递，使用目标环境已有认证。
- `OrchestrateMath.exe` 离线、按需运行，完成后退出；失败保留公式原文。
- 主程序与测试复用生产静态库；构建产物、个人数据和本地工具元数据不纳入 Git。
