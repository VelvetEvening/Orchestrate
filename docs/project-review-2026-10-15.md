# Orchestrate v2.0.0 发布前审查

审查范围为 v2.0.0 源码：动态参数表单、声明解析、Windows/WSL/SSH 状态和命令通道、SQLite 保存与迁移、日记/提醒/项目正文、托盘及自启、内置定时关机、更新器与便携打包。与上一正式版本 v1.2.0 的功能变化集中在自动化表单；其余模块复核关键路径并运行现有隔离回归。

## 发现并修复

| 问题 | 影响与复现 | 修复 |
| --- | --- | --- |
| P2：整数标识经 double 转换后丢失精度 | JSON 中的 `9007199254740993` 被转换成 `9007199254740992`，可能把错误标识传给工具 | 保留 Qt JSON 的有符号 64 位整数；覆盖 `2^53 + 1`、INT64_MIN、INT64_MAX 与普通小数 |
| P2：状态支持的静态下拉刷新后更换有效选择 | 首次选择 Alpha，外部状态改为 Beta，点击表单刷新会自动变成 Beta | 状态默认值只在首次成功读取时用于预选，后续刷新保留当前有效选择，与动态列表一致 |

两项均先由隔离测试复现失败，再修复实现。新增回归分别为 `scalarIntegersKeepPrecision` 与 `staticStateChoiceKeepsValidSelectionOnRefresh`。本地测试按仓库现有约定保留在忽略的 `app/tests/` 中，不随源码和发布包上传。

## 核验重点

- 表单只读登记的状态 JSON，不运行账号查询、授权或资源启停命令。表单使用独立快照，失败不沿用旧列表执行；重复值、错误结构、空必填列表和过期状态会被拦截。取消表单不创建命令进程。
- 工具或命令在模态表单打开期间被替换时，执行前重新核对登记目标、路径、命令及风险标记，拒绝按旧表单启动新配置。
- Windows 状态读取离开 GUI 线程；WSL 使用独立 argv，SSH 使用固定读取命令与 POSIX 引号。请求关闭后不向已销毁表单回调，远端读取保留超时和大小上限。
- 工具资料与命令在同一 SQLite 事务保存；旧结构迁移前备份，未来结构拒绝打开。项目大纲保存失败时阻止退出，文本渲染不解释任意 HTML、链接或图片。
- 更新器核验压缩包与逐文件 SHA256，拒绝路径逃逸和链接；保留个人数据与外部配置，失败回滚。新版窗口实际可见和计划任务恢复成功后才清理对应备份。
- 便携包从干净的已提交源码重新构建，仅安装程序、运行库、插件、许可说明、更新器与内置工具。发布前另做压缩包身份、逐文件校验及隔离原生启动验收。

## 本地回归与边界

环境：Windows 11、Qt 6.11.2、MinGW GCC 13.1。验收使用合成 SQLite、临时文件、辅助进程和模拟计划任务，不使用实际工具账号，也不启停 NPU 或执行真实关机。

修复后 19 个 CTest 套件全部通过。协议套件为 32 passed / 0 failed / 1 skipped（默认跳过真实 WSL），另行启用的 WSL 回归为 3 passed / 0 failed。本轮范围内未发现仍需阻止发布的问题。

完整 CTest 涵盖数据库、工具协议、文本/项目界面、托盘启动、自启隔离、内置工具、更新回滚/清理与关机脚本的模拟分支。协议测试另覆盖动态选择、只读上下文、快照校验、错误恢复及模拟 SSH 的登记用户和特殊字符路径。真实 WSL 验收仅在 Ubuntu-24.04 的随机临时目录中运行合成工具，覆盖动态选项读取与当前账号预选，完成后清理该临时目录。

真实 SSH 服务器、第三方账号切换、NPU 生命周期、Windows 重启后的真实计划任务、多屏与不同 DPI 的完整现场行为不属于本次自动验收范围。同一工具互斥仍限于客户端进程；业务锁、权限和账号核验由工具负责。上述边界不因主版本号提升而改变。
