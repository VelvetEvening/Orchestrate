# Use the time-sequence records calendar as the landing page

Orchestrate 第一版不单独设置概览页。用户启动或从托盘打开主窗口后，直接进入“时序记录”的日历页面；日历既是时序记录的主要界面，也是 Orchestrate 的首页骨架。时序记录不显示自动化工具周期任务，避免把工具调度信息与用户的日期安排混在一起。

时序记录包含两类日期内容：未来事项提醒和个人日记。用户选中某天后，可以查看该日提醒并添加一条或多条日记；日记支持按年月日检索。自动化工具的异常不通过概览页集中展示，而在左侧对应导航项或工具组位置显示异常标记。

## Consequences

- 主导航不包含“概览”，默认入口为时序记录日历。
- 第一版可以先完成日历页面骨架，再逐步加入提醒和日记能力。
- 自动化工具周期任务不绘制到日历；工具状态仍在自动化工具页面和左侧标记中查看。
- 后续若要加入全局汇总，应证明它提供了日历和侧栏无法提供的信息，否则不另建概览页。
