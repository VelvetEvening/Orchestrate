# Organize automation tools in global groups

用户希望先建立“签到”等空分组，再逐步注册属于该主题的自动化工具。Orchestrate 采用全局的自动化工具组作为逻辑容器，而不把它混同于文件系统目录、项目目录或标签：组允许为空，一个工具最多归入一个组，未分组的工具仍可存在。项目关联保持在具体工具上，而非工具组上。第一版仅提供一级工具组，不提供嵌套；管理页可按组浏览全部或未分组工具。

采用工具组而非多标签，是为了让“先建一个空容器、再添加工具”成为明确的工作流，并简化工具的归属与移动操作。未来如需跨组发现工具，可以另行评估标签或搜索，而不是提前实现多归属。
