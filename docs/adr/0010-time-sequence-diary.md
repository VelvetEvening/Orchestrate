# Add date-centered diary entries to time-sequence records

Orchestrate 将原“时约提醒”统一改名为“时序记录”。时序记录以日历为入口，除了管理未来事项，还允许用户在选中的日期下添加个人日记，用来记录当天完成了什么、发生了什么或需要回顾的内容。日记按日期组织并支持按年、月、日选择检索；同一天可以有多条日记，日记允许编辑和删除。日记可以可选关联一个项目，但不要求每条日记都属于项目。

日记与项目中的工作记录不同：工作记录属于项目，日记属于日期中心的个人时间线。第一版以日期选择和日记列表为核心，不预先扩展为复杂的全文检索或时间范围分析系统。

## Consequences

- 日历首页至少需要区分当天的提醒和日记内容。
- 同一天可以有多条日记，每条记录至少包含正文以及创建、更新时间。
- “时约提醒”保留为历史称呼，产品界面与新文档统一使用“时序记录”。
