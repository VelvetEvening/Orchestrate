# Mark automation problems in the navigation instead of adding an overview page

> 实现状态（2026-09-29）：当前工具行显示最新结果文字和颜色；组级/导航级异常角标、已读清除、失联和过期自动判定尚未实现。下述内容是待落地的设计决策，不可作为适配器依赖。

Orchestrate 不通过单独的概览页汇总自动化工具异常。工具、工具组或自动化工具导航项可以显示特殊标记，提醒用户存在失败、部分成功、失联、状态未知或逾期等需要关注的问题。第一版采用简单规则：用户打开对应位置后标记即可清除；后续如发现这会掩盖尚未解决的问题，再升级为按状态恢复清除。
