# 记录中的公式

日记、提醒、项目大纲以及协作记录的正文和摘要，在“预览”模式自动显示公式。粘贴后切换到预览即可；独立公式建议前后各留一个空行。

行内公式使用 `\(q_t\)` 或 `$q_t$`。独立公式使用 `\[…\]` 或 `$$…$$`，可跨多行。例如，下面整段可以直接粘贴到记录的编辑区：

```text
# 注意力与 KV Cache
当前查询向量为 \(q_t\)，历史键和值为 $K_{1:t}$、$V_{1:t}$。

\[
o_t=\operatorname{softmax}\left(
\frac{q_tK_{1:t}^{\mathsf T}}{\sqrt{d_k}}
\right)V_{1:t}
\]

## 对 V 加权求和
\[o_t=\sum_{j=1}^{t}\alpha_{t,j}v_j\]

$$\begin{bmatrix}1 & 2 \\ 3 & 4\end{bmatrix}$$
```

支持常用分数、根号、上下标、希腊字母、求和、积分、矩阵、对齐、箭头和 `\text{中文注释}`。公式随 Ctrl＋滚轮缩放。宽公式可以横向滚动查看。

编辑、撤销和保存始终保留文本；在预览中选中并复制公式，也会得到含分隔符的 LaTeX 原文。反引号包住的代码、围栏代码块和转义的美元符号不转换，金额如 `$5`、`$10` 保留原样。

这是现有标题预览的公式扩展，不是完整的 Markdown/LaTeX 文档编译器。链接、HTML、外部图片及其他 Markdown 语法继续按原文展示。列表和悬停提示中的公式也保留原文，打开记录才生成排版。

不支持的命令、不完整或过于复杂的公式保留原文，不影响编辑和保存。每份预览最多尝试前 128 个公式片段，单个公式不超过 4096 字符、括号嵌套不超过 32 层；不执行自定义宏、文件引用和外部命令。排版在独立进程完成，超过 5 秒或资源限制会结束该次渲染；继续编辑后可重新预览。单次结果缓存限制为 16 MiB，普通记录和空闲时不运行公式进程。
