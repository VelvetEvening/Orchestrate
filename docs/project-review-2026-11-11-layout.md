# v3.2.1 布局调整、稳定性与后台资源审查

审查范围是 `design/page-layout` 相对 v3.2.0 的六个提交，功能末提交为 `652d546`：全局融合顶栏、移除重复模块标题、剪贴板设置迁移、原生标题栏重绘修复及移除自动化周期刷新。发布准备只更新版本和文档，没有追加界面功能。

## 崩溃与日常操作

检查主窗口创建和销毁、原生消息回调、导航与菜单对象归属、剪贴板监听保存失败回退、状态缓存到期及异步读取取消。未发现容易通过常规操作触发的新崩溃或阻塞发布的问题。

- 顶栏在 `buildUi()` 创建后配置；数据库初始化失败会提前进入原有不可编辑状态，不会访问尚未创建的顶栏。Windows 消息处理仅拦截融合顶栏的 `WM_NCACTIVATE`，实际激活和其余消息继续交给 Qt。
- 设置按钮持有菜单，菜单持有 QAction；监听回调以页面为连接上下文，随页面销毁解除连接。移除复制按钮后，双击、Enter 和右键入口仍保留。
- 缓存到期使用页面持有的单次定时器；无未来到期状态时停止。读取失败、移除注册和重新读取声明会重新安排到期时间，不会继续读取旧工具状态。
- 工具页原有销毁路径继续在成员销毁前断开、停止并清理 QProcess，异步本地读取也检查所有者生命期。相关取消和关闭页面测试通过。

新增本地循环回归完成 **12 次主窗口创建/销毁、1200 次页面切换、240 次菜单打开、480 次监听切换**，并覆盖侧栏收放和窗口隐藏恢复。未崩溃；每轮销毁后的 QWidget 数量没有累积。监听切换在 offscreen 下完成，不读取用户系统剪贴板。

Windows 原生专项覆盖初次打开、激活、失活、整窗重绘、最大化、还原、最小化恢复和托盘恢复。八个场景的采样顶栏区域均保持预期浅色，没有旧式标题栏覆盖。另复核最小窗口下的剪贴板、自动化工具和各页导航截图。

版本更新后的完整 **22 个 CTest 套件通过**，其中界面套件包含上述循环测试。覆盖公式、记录与保存保护、剪贴板、工具接入、数据库、启动、自动更新、便携更新及任务恢复。原生标题栏专项独立执行；真实 WSL/SSH 业务、关机任务和个人数据不在此次测试操作范围内。

## 后台资源对比

Windows 11 / Qt 6.11.2 / MinGW 13.1，Release 构建。基线来自已发布的 v3.2.0 ZIP，候选为本次 v3.2.1 构建；均使用同套便携运行库。每份独立合成数据库含 3 个项目、15 条协作记录和 30 条剪贴板内容，没有外部工具注册；关闭全局快捷键与自动更新联网。

两份原生程序都关闭主窗口到托盘，确认进程仍运行、窗口已隐藏；两份监听程序在 offscreen 下隔离系统剪贴板。预热后每 5 秒采样一次，共 37 次、约 183 秒。原始数据及二进制 SHA256 保存在本地 `app/build-qt/layout-resource-review.json`。

源码确认此次没有新增后台轮询或常驻服务。自动化旧的 30 秒周期刷新检查已删除；状态到期只更新缓存显示，不查询数据库、不读取文件、不启动 SSH/WSL。剪贴板继续采用复制事件加 30 ms 单次防抖；原有提醒检查和按日更新调度保持不变。
