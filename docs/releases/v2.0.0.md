# Orchestrate v2.0.0

自动化工具的命令表单现在能直接读取工具公开的选项。账号、设备、服务器和环境可以用动态下拉选择；工具作者不再需要让用户记住并手填标识。

## 新增与改进

- `choice.options_state_key` 从状态 JSON 的点分路径读取 `{value, label, description?}` 数组，兼容已有静态 `options`。
- `state_key` 仅预选仍然有效的当前项；选择失效、缺失或为 null 时留空，不自动切到第一项。
- 使用状态的表单在打开时异步读取；Windows、WSL 和 SSH 均有加载、失败重试及空列表提示。状态读取不执行工具业务。
- `type: "readonly"` 在表单顶部展示当前账号、环境及最近核验时间等公开上下文，不参与命令参数替换。
- 显式刷新保留仍有效的选择和已编辑输入；运行前检查必填项、选项快照及状态有效期。工具执行时仍需自行核验身份和权限。
- 修复静态下拉刷新时可能更换有效选择的问题；修复大于 `2^53` 的整数标识转为文本时丢失精度的问题。

## 升级与接入

本版沿用 schema v3。从 v1.2.0 升级无需数据库结构迁移；个人数据、工具注册和刷新偏好按现有更新流程保留。v1.1.0 及以上可在“设置 → 版本与更新”下载并安装正式 Release；安装前先结束运行中的工具命令和关机倒计时。

现有静态工具声明继续可用。工具作者若要使用动态选项或只读上下文，需按[接入指南第 7 节](../automation-tool-contract-v1.md#动态选择与只读上下文)更新声明和状态生产者，再在客户端选择“重新读取声明”；仅升级客户端不会自动改造外部工具。新字段要求 v2.0.0 或更新版本，状态不得包含密码、令牌或 Cookie。

发布附件为 `Orchestrate-v2.0.0-windows-x64.zip` 及对应 `.zip.sha256`。完整解压运行，保留 DLL、插件、更新器和工具目录；发布包不含个人数据库、凭据及运行状态。

验证与边界见[发布前审查记录](../project-review-2026-10-15.md)。
