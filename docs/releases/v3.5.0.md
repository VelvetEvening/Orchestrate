# Orchestrate v3.5.0 · 原生 Markdown 即时编辑

- 日记、提醒说明、协作记录正文和摘要采用 Qt 原生即时编辑。编辑当前段落时，其他内容的标题、公式、表格和文字格式持续保持排版；点击已渲染的段落、公式或单元格即可修改，离开后恢复排版。
- 支持 Markdown 表格显示、单元格编辑、Tab／Shift+Tab 移动，以及右键插入和删除行列；超出窗口宽度时可横向滚动。基本列表、引用、代码块、加粗、斜体、删除线和文字链接共用排版。
- Markdown 原文继续负责保存和撤销，切换显示方式不改写内容。整篇源码入口移至右键菜单，并提供“返回即时编辑”，不再常驻源码按钮。
- 复用未变化的排版片段和公式结果，减少连续输入时的重复渲染；保留中文输入法组合输入、跨段选择和跨模式撤销。
- 工具组底部仅保留“新建工具组”和“注册工具”。注册下拉菜单统一包含本地、WSL 和 SSH 服务器工具；工具组重命名与删除通过右键菜单操作。

数据库继续使用 **schema v8**，从 v3.4.x 升级无需新增结构迁移。保留主窗口内容导航、独立打开和草稿保护。HTML、外部图片、复杂嵌套和扩展语法不作为完整 Markdown 支持，不加载外部资源。

可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.5.0-windows-x64.zip` 完整解压；同时提供 `.zip.sha256` 校验文件。请保留 `OrchestrateMath.exe` 和随附依赖。正式包不包含个人数据、工具状态或本地测试内容。
