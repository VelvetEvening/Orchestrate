# Orchestrate v3.0.1

调整剪贴板内容的删除确认，方便清理日常历史，同时对自建标签页中保存的内容增加一次确认。

- **历史标签页**：删除选中内容立即执行，不再弹窗确认。
- **自建标签页**：先选择“继续”，再选择“确认删除”才执行删除。任一次选择“取消”、关闭弹窗或按 Esc，内容均保留；两次弹窗默认选中“取消”。
- 规则按条目所在标签页判断，适用于手动保存内容、文件夹内条目、搜索结果和多选删除。删除按钮和右键菜单行为一致，删除仍无法撤销。
- 删除标签页或文件夹的行为保持不变：一次确认后解除分类，保留其中内容；删除自建标签页时内容移回“历史”。

数据库仍为 **schema v7**，无需结构迁移；已有内容、顺序和设置保留。本次没有增加后台任务。

可在“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.0.1-windows-x64.zip`；同时提供 `.zip.sha256` 校验文件。

## 验证

21 项本地回归全部通过。新增隔离测试覆盖历史直接删除、自建页两次确认、任一步取消、Esc／关闭弹窗／默认回车取消、标签页调序、文件夹与搜索结果的多选删除、右键入口、确认期间继续复制，以及删除失败时整笔事务回滚。原有分类删除保留、自动历史清理、编辑保护和更新交接测试均通过。
