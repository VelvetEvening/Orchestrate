# v3.6.0 可配置工具与命令

本版让现成工具更容易接入，也可以在界面中调整命令和运行参数。

- 统一“接入工具”入口，同窗选择“工具目录”或“JSON 配置文件”，支持本地 Windows、WSL 和 SSH。目录中已有标准声明时优先读取，没有声明时从入口和帮助发现命令；JSON 文件沿用 `orchestrate-tool/v1`，状态文件可省略。
- 默认接入整组命令，按需展开挑选、编辑或手动添加。命令名称下显示单行简介，可新增、编辑、启停、删除及拖动排序；配置读取失败会清除旧结果，防止误用。
- 运行参数支持文本、整数、小数、时间、开关、文件、目录和下拉选项。下拉可来自固定列表、文件或查询命令，并随项目、账号等上游选择联动。
- 无声明工具可根据明确的查询帮助自动关联下拉来源；支持 JSON、逐行列表和有列名表格，无列名表格可首次选列并保存。查询失败或上游变化时，旧选项不能继续用于运行；实际参数值必须由工具完整提供。
- 非交互命令在应用内显示输出和退出码，交互任务可在外部终端运行。打开终端只表示启动交接，业务结果和结束状态仍在终端查看。
- 保留手动修改的内置工具配置。重复接入同一目录会补充缺失命令和空白简介，保留已有调整；替换声明或恢复默认前先展示配置对照。

工具作者可参照[统一 JSON 最小模板与接入指南](https://github.com/VelvetEvening/Orchestrate/blob/v3.6.0/docs/automation-tool-contract-v1.md)。目录发现、动态下拉、CANNLab 示例及解析范围见[可配置工具说明](https://github.com/VelvetEvening/Orchestrate/blob/v3.6.0/docs/development/configurable-tools.md)。

数据库升级至 **schema v9**，迁移前自动备份；工具与状态协议仍为 v1。降级时须同时恢复升级前的数据库。
