# Orchestrate v2.3.1

项目记录中的协作记录文件夹支持重点标记，常用分类可以显示星标并置顶。

## 文件夹重点标记

- 右键文件夹选择“标记重点并置顶”，文件夹显示金色五角星，排在当前项目的普通文件夹之前。
- 多个重点文件夹之间仍按名称排序；选择“取消重点标记”恢复普通文件夹图标和名称排序。
- 标记随便携数据库保存，重命名、切换项目和重启后继续保留，各项目独立管理。
- 标记与取消时保留搜索条件、当前选择及文件夹展开状态；保存失败会显示错误并保留原状态。

## 数据与升级

本版将数据库从 schema v5 升级至 v6。迁移前自动在程序旁的 `data/backups/` 保存数据库快照；迁移在事务内执行，失败会回滚。

已有文件夹默认未标记重点，文件夹名称、记录归属、标题、摘要、正文及创建／更新时间均保留。项目状态、大纲、工具注册和其他偏好继续保留。手动降级时需同时恢复旧程序和升级前的数据库备份。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.3.1-windows-x64.zip` 完整解压运行；附件同时提供 `.zip.sha256` 校验文件。安装前请结束运行中的工具命令和关机倒计时。
