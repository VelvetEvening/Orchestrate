# Orchestrate v2.1.0

自动化工具页更简洁：日常操作聚焦工具状态和命令，介绍与连接位置按需查看。

## 界面改进

- 工具名称下方不再常驻展示介绍；悬停工具名称可查看完整说明。
- 命令改为单行，保留需填参数、高风险、交互式标签；命令介绍与执行信息通过悬停查看，参数表单保留填写帮助与风险提示。
- 移除状态更新时间、状态日期及页面上的“刷新状态”按钮；右键左侧工具仍可手动刷新，周期刷新设置保持可用。
- 远程工具只显示 SSH/WSL 类型标签，主机、登录用户与路径不再常驻展示。
- 新增右键菜单“查看工具信息”，集中展示可复制的主机或发行版、用户、接入声明、工作目录及状态文件路径；本地与内置工具同样可查看位置。

## 升级说明

本版沿用 schema v3，现有工具声明继续兼容。从 v2.0.0 升级无需数据库结构迁移；个人数据、工具注册和刷新偏好按现有更新流程保留。

可在“设置 → 版本与更新”检查并安装正式 Release，或下载 `Orchestrate-v2.1.0-windows-x64.zip` 完整解压运行。发布附件同时提供 `.zip.sha256` 校验文件。安装前先结束运行中的工具命令和关机倒计时。
