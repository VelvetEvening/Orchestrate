# Orchestrate v2.1.2

修复自动化工具命令参数窗口在状态读取尚未结束时关闭，可能导致整个程序退出的问题。SSH/WSL 注册窗口共用的异步读取通道也获得同样的保护。

原因是窗口销毁子进程时仍可能收到完成信号，回调继续访问已销毁的窗口成员。本版将读取请求放在独立的对象中，窗口关闭时先断开回调，再释放子进程；正常完成、失败、超时与输出上限的处理继续保留。

本版沿用 schema v3，工具声明、状态格式、个人数据及刷新偏好继续兼容。从 v2.1.1 升级无需数据库结构迁移。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.1.2-windows-x64.zip` 完整解压运行。附件同时提供 `.zip.sha256` 校验文件。
