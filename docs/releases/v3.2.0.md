# Orchestrate v3.2.0

全新的浅色工作台，让日常阅读、记录和工具操作更清楚、简洁。

- **统一浅色界面**：导航、标题栏、四大模块、设置、独立编辑窗口、菜单和运行输出统一为浅灰、白色与雾蓝，配合线性图标和清楚的键盘焦点。
- **精简重复信息**：移除侧栏重复应用名、“工作台”字样，以及日历右侧重复的日期与条数概览；提醒和日记直接呈现。
- **项目操作更集中**：项目状态改用圆点圆环与圆环勾选，悬停可查看状态；项目设置放在项目列表右键菜单末尾。新建文件夹移到项目大纲旁，删除重复的协作记录标题。
- **补齐日常反馈**：项目大纲支持单击、回车或空格打开，并显示自动保存结果；协作记录保存、空列表、搜索无结果和运行失败的反馈保持清晰。窄窗口下的工具标题可换行。

保留原有记录、公式预览、排序、剪贴板和工具接入能力。主题使用原生 Qt 控件与内置 SVG，不引入常驻动画或新的后台轮询。

数据库仍为 **schema v7**，从 v3.0.x / v3.1.0 升级无需结构迁移。可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.2.0-windows-x64.zip`；同时提供 `.zip.sha256`。请完整解压并保留 `OrchestrateMath.exe` 及随附依赖。

## 验证

发布前完整 22 个 CTest 套件通过，覆盖日记、提醒、项目设置与删除保护、协作记录保存、剪贴板、公式预览、启动、数据库与便携更新。按常规工作量复核窗口和对象生命周期，并测量旧版与新版的空闲资源占用；本轮未发现阻塞发布的崩溃或后台持续增长问题。具体范围与测量见[审查记录](https://github.com/VelvetEvening/Orchestrate/blob/v3.2.0/docs/project-review-2026-11-11.md)。
