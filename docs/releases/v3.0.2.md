# Orchestrate v3.0.2

简化自建标签页中剪贴板内容的删除流程，移除 v3.0.1 多余的一次确认弹窗。

- **自建标签页**：点击删除后只弹一次确认，点击“确认删除”即删除选中内容。
- **历史标签页**：保持直接删除，不弹确认。
- 选择“取消”、关闭弹窗或按 Esc 均保留内容，弹窗默认选中“取消”。删除按钮、右键菜单、文件夹内条目、搜索结果和多选删除遵循同一规则。

删除标签页或文件夹仍保留其中内容。数据库仍为 **schema v7**，无需结构迁移；已有内容、顺序和设置保留。

可在“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.0.2-windows-x64.zip`；同时提供 `.zip.sha256` 校验文件。

## 验证

21 项本地回归全部通过。删除交互测试明确校验自建页只出现一次确认、历史页零确认，并覆盖取消、Esc、关闭弹窗、默认回车、搜索、文件夹、多选、右键入口、确认期间继续复制及删除失败回滚。
