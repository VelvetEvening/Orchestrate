# v3.6.1 剪贴板阅读与编辑导航

- 剪贴板列表、内容预览和编辑正文由 10pt 放大至 **18pt（1.8 倍）**，列表行高随文字适配，阅读更清楚。
- 顶部标签页改为相连叠压的样式，选中项抬高并覆盖相邻边缘。保留历史星标、拖动排序、跨标签归类和横向滚动，长标签自动省略。
- 日记、提醒、协作记录的即时／源码编辑及剪贴板编辑，在首个视觉行按 **↑ 到文首**、最后一个视觉行按 **↓ 到文末**；Shift+↑/↓ 可选择到对应边界。自动换行仍逐行移动，不插入空行或修改正文。

数据库保持 schema v9，复制格式和后台任务沿用。

## 验证

2026-11-14 用户验收通过。开发构建成功，首轮剪贴板、内容导航、Markdown 编辑和 Windows 原生启动四个套件通过；最终标签叠压及向上导航调整后，两个受影响的 `clipboard`、`markdown_edit` 套件通过（6.37 秒），分别为 22 passed、13 passed。

检查了普通／紧凑窗口、编辑正文以及多标签首尾滚动。键盘回归覆盖即时编辑、源码和普通文本编辑中的首尾边界、自动换行、Shift 选择、继续输入及撤销。测试使用隔离数据；本轮未重新验收真实输入法与多屏 DPI。

实现和检查范围见[开发说明](https://github.com/VelvetEvening/Orchestrate/blob/v3.6.1/docs/development/clipboard-readability.md)。
