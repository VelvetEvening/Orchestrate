# Orchestrate v2.2.0

项目记录支持状态管理和文件夹分类，更方便整理与 AI 协作的过程、任务要求和提示词。

## 新增与改进

- 右键项目可在“进行中”和“已完结”之间切换，列表直接显示状态，默认进行中；已完结项目仍可查看和编辑。
- “工作记录”更名为“协作记录”，右侧“项目大纲”和“项目设置”继续保留。
- 新增项目内文件夹，可按初始化工作区、界面优化等用途自由分类；支持新建、重命名、展开和收起，并记住展开状态。
- 选中文件夹后添加的记录直接归入该分类；右键记录可移动到其他文件夹或项目顶层。删除文件夹会保留其中的记录并移回顶层，不改动磁盘目录。
- 搜索支持记录简介和文件夹名称，自动展开匹配内容；清空搜索后恢复原来的展开状态。

## 数据与升级

本版将数据库从 schema v3 升级至 v4。迁移前自动在程序旁的 `data/backups/` 保存完整数据库快照；迁移在事务内执行，失败会回滚。

已有项目默认标记为“进行中”；原有记录的简介、正文、创建时间和更新时间均保留，并放在项目顶层。项目大纲、工具注册和其他偏好继续保留。手动降级时需同时恢复旧程序及升级前的数据库备份。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.2.0-windows-x64.zip` 完整解压运行。附件同时提供 `.zip.sha256` 校验文件。安装前请结束运行中的工具命令和关机倒计时。
