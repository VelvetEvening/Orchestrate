# Orchestrate v3.2.1

延续浅色工作台，精简日常布局，并修复窗口顶栏偶发重复绘制的问题。

- **融合顶栏**：侧栏开关移至固定的左上角，去掉重复的应用名与模块标题，保留窗口拖动、缩放、最大化、最小化和托盘操作。
- **修复顶栏重绘**：窗口激活、失活及恢复时，不再出现旧式渐变标题栏、应用名和重复窗口按钮覆盖浅色顶栏的问题。
- **剪贴板设置集中**：右下角“设置”提供监听开关和历史设置；删除常驻“复制并收起”按钮，双击、Enter 和右键菜单继续可用。
- **移除周期刷新**：自动化工具不再提供周期刷新设置，也不再每 30 秒检查到期读取。保留启动、选择工具、命令结束及手动刷新；缓存到期时仍显示“已过期”。旧刷新偏好仅为兼容保留，不再触发后台轮询。

数据库仍为 **schema v7**，从 v3.2.0 升级无需结构迁移。可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.2.1-windows-x64.zip`；同时提供 `.zip.sha256`。请完整解压并保留 `OrchestrateMath.exe` 及随附依赖。

## 验证

完整回归及专项审查覆盖常规记录操作、剪贴板、工具接入、异步读取退出、数据库、便携更新和原生窗口恢复。另反复创建销毁 12 个主窗口，完成 1200 次页面切换、240 次菜单打开和 480 次监听切换；未发现崩溃或控件累积。

与 v3.2.0 使用同规模合成数据进行后台对比采样，未发现空闲 CPU 或内存明显增加。测量范围、具体数值和限制见[稳定性与后台资源审查](https://github.com/VelvetEvening/Orchestrate/blob/v3.2.1/docs/project-review-2026-11-11-layout.md)。
