# v3.3.0 · 项目 Git 历史（开发版）

- 项目设置支持本地、WSL、SSH 目录；自动发现环境和默认用户，远程验证后固定实际用户与目录。
- “项目大纲”替换为“Git 历史”。每个项目有独立、可调整大小的历史窗口，支持提交关系图、分支和标签筛选、分页、查找、提交说明、文件和 Diff。
- 分支对比直接查询所选 Git 远端，完整显示同名分支的一致／不一致以及仅本地／仅远端分支；不拉取代码，不建立仓库缓存。
- 读取异步执行，关闭窗口结束读取；刷新失败保留本次窗口的上次成功内容。
- 双击项目目录：本地沿用资源管理器，WSL 打开对应 Linux 目录，SSH 显示主机和路径并提供复制。

数据库升级至 **schema v8**，升级前自动备份。旧目录按本地绑定保留；大纲功能及专用数据直接移除，不转换为协作记录。降级须同时恢复旧程序和升级前数据库。

实现范围与现场检查见 [开发说明](../development/git-history.md)。本文件记录开发分支内容，不表示已经发布或完成原生桌面验收。
