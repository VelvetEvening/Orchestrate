# Orchestrate v3.3.0 · 项目 Git 历史

- 项目设置支持本地、WSL、SSH 目录；自动发现环境和默认用户，远程验证后固定实际用户与目录。
- “项目大纲”替换为“Git 历史”。每个项目有独立、可调整大小的历史窗口，支持提交关系图、独立的分支与标签筛选、分页和查找。双击提交或按 Enter 查看说明、文件和 Diff；单击只定位，详情窗口复用。
- 分支对比直接查询所选 Git 远端，完整显示同名分支的一致／不一致以及仅本地／仅远端分支；不拉取代码，不建立仓库缓存。
- 读取异步执行，成功时只显示读取状态，不显示数量与读取时间；关闭窗口结束读取；刷新失败保留本次窗口的上次成功内容。
- 双击项目目录：本地沿用资源管理器，WSL 打开对应 Linux 目录，SSH 显示主机和路径并提供复制。

数据库升级至 **schema v8**，升级前自动备份。旧目录按本地绑定保留；大纲功能及专用数据直接移除，不转换为协作记录。降级须同时恢复旧程序和升级前数据库。

可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.3.0-windows-x64.zip`；同时提供 `.zip.sha256`。请完整解压并保留 `OrchestrateMath.exe` 及随附依赖。正式包不包含个人数据、工具状态或本地测试内容。

Git 需要在绑定目录对应的本地、WSL 或 SSH 环境中安装并可从 PATH 调用。查询远端依赖该环境的网络和已有认证；网络失败时保留上次成功内容，不影响本地提交历史。实际 WSL／SSH 认证依赖用户环境。

## 验证

发布前完整构建成功，**23 组 CTest 回归全部通过**，包括原生窗口启动、便携更新和 Git 专项测试；测试使用隔离数据。

本地 Git 原生界面已检查，覆盖独立分支／标签筛选、单击选中、双击查看提交说明和 Diff、关闭详情保留原选择，以及实时远端分支查询。

自动化测试覆盖分页、根提交／合并／重命名／二进制 Diff、字面路径、四种分支状态、大量分支完整读取、失败保留、关闭取消、模拟 SSH、环境绑定和 schema v7 → v8 的备份迁移。模拟 SSH 不替代实际服务器认证验收。

实现范围与检查记录见 [开发说明](../development/git-history.md)。多窗口管理调整不包含在此版本中。
