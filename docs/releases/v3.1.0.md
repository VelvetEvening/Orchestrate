# Orchestrate v3.1.0

记录预览现在可以离线显示 LaTeX 数学公式，适合保存 AI 对话中的注意力公式、推导和研究笔记。

- **自动公式排版**：支持 `\(…\)`、`\[…\]`、`$…$`、`$$…$$`，包含分数、上下标、根号、求和、矩阵和中文注释。
- **覆盖记录阅读界面**：日记、提醒、项目大纲、协作记录正文与摘要均可使用。公式支持文字缩放，宽公式可滚动查看。
- **保留可编辑原文**：编辑、保存、撤销和预览复制均保留 LaTeX 文本；代码示例、金额及转义符不会当作普通公式处理。
- **按需渲染**：公式在独立进程异步排版，完成后退出；异常、超时或超过资源限制时保留原文。普通文本不启动公式进程，空闲时不新增轮询。

仍保留三级标题和原有记录操作，其余 Markdown 语法继续按字面文本展示。公式使用常用 LaTeX 命令子集，不支持自定义宏或文件引用；详情与可复制样例见 [公式说明](https://github.com/VelvetEvening/Orchestrate/blob/v3.1.0/docs/math-preview.md)。

数据库仍为 **schema v7**，从 v3.0.x 升级无需结构迁移。可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.1.0-windows-x64.zip`，同时提供 `.zip.sha256`。请完整解压并保留新增的 `OrchestrateMath.exe`。

## 验证

本地 22 个 CTest 套件通过，包含公式渲染、复制、缩放、快速切换、错误公式、渲染进程异常退出与恢复，以及原有记录、剪贴板、数据库和更新回归。另检查普通与紧凑窗口、30 次连续预览后的内存变化、空闲 CPU 和长文本扫描。测试期间未发现新的主程序崩溃或持续内存增长；这些检查不代表覆盖所有 Windows 环境或全部 LaTeX 输入。
