# Orchestrate v3.2.2

将浅色工作台调整为连续分区，让不同模块通过细微底色变化直接衔接。

- **连续工作面**：时序记录、项目记录、自动化工具、剪贴板和设置取消外围卡片间隙与重复描边，留白放在分区内部；侧栏、索引和正文使用相邻的浅灰、灰白和白色。
- **独立窗口操作栏**：统一浅灰顶栏独占一行，左侧收起/展开，右侧为原生最小化、最大化和关闭；工作区从下方开始，切换页面或拖动分栏不会改变顶栏底色。
- **更轻的操作与内容层次**：次要按钮弱化外框，剪贴板页签使用底线标识选中，日历采用连续底色；项目与工具分栏保留拖动调整。
- **工具与设置布局**：工具分组和注册入口集中在左列底部，右侧信息、状态及命令连续排列；设置页使用平面分节。
- **键盘焦点**：主要按钮与默认按钮保留清晰的焦点边框，支持 Tab 操作。

数据库仍为 **schema v7**，从 v3.2.1 升级无需结构迁移。已有数据、快捷键、记录编辑、工具运行和剪贴板操作保留；此次没有新增轮询或常驻后台任务。

可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.2.2-windows-x64.zip`；同时提供 `.zip.sha256`。请完整解压并保留 `OrchestrateMath.exe` 及随附依赖。正式包不包含本地验收示例数据。
