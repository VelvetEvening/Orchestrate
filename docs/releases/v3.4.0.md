# Orchestrate v3.4.0 · 内容导航

- Git 历史与提交详情、日记集合与正文，以及提醒、协作记录和剪贴板编辑默认在主窗口内打开，减少逐级弹出大窗口。
- 提醒、日记和协作记录列表统一双击或 Enter 打开，移除重复的“编辑／打开／查看日记”按钮。
- 内容页统一提供返回、独立打开和关闭。返回及模块切换保留现场与草稿；关闭、退出或安装更新时处理未保存修改。
- 独立打开和收回移动同一份内容，保留选择、阅读位置、字号与撤销记录；独立窗口内查看下级详情仍在原窗口中切换。
- 日记与提醒补齐关闭时的保存保护、Ctrl+S 和原位保存反馈；保存失败保留输入。
- 剪贴板自动历史清理保护所有保留中的编辑条目，保存草稿不会覆盖用户之后调整的分类。

沿用浅色连续工作台和现有 Git 只读能力。数据库仍为 **schema v8**，没有新增结构迁移、后台轮询或常驻进程。

可通过“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.4.0-windows-x64.zip`；同时提供 `.zip.sha256`。请完整解压并保留 `OrchestrateMath.exe` 及随附依赖。正式包不包含个人数据、工具状态或本地测试内容。从 v3.3.0 升级不改变数据库结构；更早版本沿用 schema v8 的备份与升级规则。

发布前 **24 组 CTest 回归全部通过**，覆盖记录保存、内容生命周期、剪贴板、Git 读取取消、数据库、公式和便携更新。

独立完成 Windows 原生窗口的 40 轮内容开关、独立打开／收回、Esc、托盘唤起和最小化恢复检查，内容控件均释放；标题栏重绘专项也通过。后台资源测量使用隔离合成数据，覆盖空闲托盘、保留多个内容页及关闭内容后的空闲状态，检查 CPU、内存、句柄与子进程。

使用规则、测量数据与验收范围见 [开发说明](../development/content-navigation.md)。本轮未覆盖多显示器、不同 DPI 和真实 WSL／SSH 服务器认证环境。
