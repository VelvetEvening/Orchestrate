# v3.4.0 · 内容导航（开发版）

- Git 历史与提交详情、日记集合与正文，以及提醒、协作记录和剪贴板编辑默认在主窗口内打开，减少逐级弹出大窗口。
- 提醒、日记和协作记录列表统一双击或 Enter 打开，移除重复的“编辑／打开／查看日记”按钮。
- 内容页统一提供返回、独立打开和关闭。返回及模块切换保留现场与草稿；关闭、退出或安装更新时处理未保存修改。
- 独立打开和收回移动同一份内容，保留选择、阅读位置、字号与撤销记录；独立窗口内查看下级详情仍在原窗口中切换。
- 日记与提醒补齐关闭时的保存保护、Ctrl+S 和原位保存反馈；保存失败保留输入。
- 剪贴板自动历史清理保护所有保留中的编辑条目，保存草稿不会覆盖用户之后调整的分类。

沿用浅色连续工作台和现有 Git 只读能力。数据库仍为 **schema v8**，没有新增结构迁移、后台轮询或常驻进程。

本文件记录开发分支，尚未发布。使用规则与验收入口见 [开发说明](../development/content-navigation.md)。
