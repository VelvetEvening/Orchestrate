# Orchestrate v3.0.0

新增剪贴板工作区，将日常复制历史和长期保存的片段纳入 Orchestrate；协作记录、工具与剪贴板内容均支持直接拖动归类。

## 剪贴板工作区

- 侧栏新增“剪贴板”，位于自动化工具与设置之间。监听可随时开关，默认关闭，重启保留选择。
- 支持文本、图片、网页富文本和复制的文件路径。固定的“历史”标签页以星形标识接收新复制内容；可新建标签页和一层文件夹，手动保存文本、修改标题或编辑纯文本。
- 文件夹与内容显示在同一列表，搜索只作用于当前标签页。支持拖动与 Ctrl+↑/↓ 调序，拖入文件夹归类，拖到其他标签页移动；顺序和折叠状态随数据保存。
- 双击条目将内容放回系统剪贴板并收起 Orchestrate，再由用户在目标位置 Ctrl+V 粘贴。富文本和图片保留原格式；文件条目保留路径，不复制原文件。
- 默认保留 500 条自动历史，仅作用于“历史”顶层的自动记录。超额时从当前列表底部向上清理；拖动调序会改变清理先后，不把条目自动变成永久保留内容。
- 手动新建、编辑保存、移动归类过的内容不参与自动清理。正在编辑的条目临时跳过，保存失败保留草稿；取消后恢复原有清理资格。
- 删除标签页或文件夹保留其中内容：分别移回“历史”或当前标签页顶层。删除具体内容需确认。
- 连续重复复制和取用自身条目不会重复收集；跳过明确标记为私密的剪贴板格式。单条原始内容上限 16 MiB，图片上限 3200 万像素。

## 拖动归类与更新修复

- 协作记录可拖入其他文件夹或移回项目顶层；工具可拖入其他工具组。移除原来的专用移动菜单，保存失败保留原归属和顺序。
- 更新替换目录遇到 Windows 短时占用时，最多尝试五次、间隔 500 毫秒。持续失败仍保留原有错误与回滚行为；目标已存在或源目录缺失时立即停止。

## 常驻与数据

剪贴板使用系统变化通知，空闲时不轮询。列表只读取摘要，完整内容和图片按需加载；隐藏时不因新复制内容重复重建列表。本版没有增加日常滚动备份或常驻备份服务，保留已有 SQLite 事务和迁移前快照。

数据库升级为 **schema v7**。从 v2.4.1 或更早版本升级时，会先在 `data/backups/` 保存一致快照，再在事务中迁移；原日记、项目、协作记录、工具和偏好保留。已有 CopyQ 历史不会自动导入。降级时须同时恢复旧版程序与对应数据库快照。

可在“设置 → 版本与更新”安装，或下载 `Orchestrate-v3.0.0-windows-x64.zip` 完整解压运行；同时提供 `.zip.sha256` 校验文件。手动替换前完全退出程序并保留 `data/`、工具状态和个人配置。安装更新前结束运行中的工具命令和关机倒计时。
