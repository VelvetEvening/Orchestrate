# v3.5.6 统一内容编辑

开发分支：`feat/v3.5.6-unified-editing`。本版将协作记录的编辑方式扩展到日记、提醒和剪贴板编辑页。

- 日记和提醒打开即可编辑，取消预览／编辑切换。Ctrl+S 保存后留在当前内容继续编辑。
- 日记、提醒和剪贴板编辑页的保存状态移到标题同行，移除底部保存／关闭按钮与状态栏，扩大内容区域。失败详情可在保存状态上悬停查看。
- 日记日期与简介同排显示；提醒的时间、重复规则和关联项目可直接修改，说明内容区位于选项下方。
- 日记与提醒默认正文改为 20pt，分别记住之后的 Ctrl＋滚轮缩放。协作记录保持正文 20pt、摘要 24pt。
- 修正协作记录摘要／正文切换的额外宽度和末项右间距，使“正文”按钮外沿与内容框右沿对齐。
- 所有编辑页在返回、Alt+左箭头、切换模块、关闭内容／窗口及关闭到托盘时处理未保存修改。保存失败或选择继续编辑时留在原界面；放弃修改恢复最近保存内容，包括提醒的所有选项。
- 独立打开与收回继续移动同一页面并保留草稿；收回前也会保护主窗口正在编辑的另一份内容。

剪贴板的富文本、图片和文件路径继续保留原始格式；可修改标题，含文本的条目可另存为纯文本。剪贴板列表预览、Git 只读详情及短表单的操作沿用。数据库保持 schema v8。
