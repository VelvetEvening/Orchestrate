# v3.5.5 协作记录直接编辑

开发分支：`feat/v3.5.5-record-editor`，尚未合并或发布。

- 打开记录即可编辑标题、摘要和正文，移除预览／编辑模式、“取消编辑”和“复制正文”按钮；需要复制时直接选择内容并复制。
- Ctrl+S 或底部“保存”一次保存三个字段，保存后继续编辑，保留当前段落、选择和撤销记录。空摘要可直接填写。
- 缩短标题输入框，将摘要／正文切换放到标题同行右侧。
- 正文默认 20pt，比用户当前摘要 22pt 略小；摘要默认 24pt。新版独立记住两者后续的 Ctrl＋滚轮缩放，不改变日记等其他内容的字号。
- 返回、Alt+左箭头、切换模块、关闭内容／窗口（包括关闭到托盘）时，有修改会询问“保存／放弃修改／继续编辑”。保存失败或选择继续编辑时留在原界面，放弃修改则恢复最近保存内容。

独立打开与收回主窗口继续移动同一页面并保留草稿。数据库保持 schema v8，未修改字段的原有换行格式继续保留。
