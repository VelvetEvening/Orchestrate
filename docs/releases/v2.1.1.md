# Orchestrate v2.1.1

恢复自动化工具页“当前状态”右上角的“刷新状态”按钮，常用操作可直接点击。右键菜单中的刷新入口继续保留；刷新只读取工具状态，不运行工具命令。

沿用 v2.1.0 的其他界面精简：介绍通过悬停查看，命令保持单行，连接来源只显示 SSH/WSL，主机、用户与路径通过右键“查看工具信息”查看。状态更新时间与日期仍不常驻展示。

本版沿用 schema v3，现有工具声明继续兼容。从 v2.1.0 升级无需数据库结构迁移，个人数据、工具注册与刷新偏好按现有更新流程保留。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.1.1-windows-x64.zip` 完整解压运行。附件同时提供 `.zip.sha256` 校验文件。
