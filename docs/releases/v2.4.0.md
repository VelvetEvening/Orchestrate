# Orchestrate v2.4.0

工具和项目条目现在可以拖动排序，顺序自动保存，重启后继续保留。

## 拖动调整顺序

- 自动化工具：调整同组工具顺序，也可移动整个工具组，包括改名后的“未分组”。
- 项目记录：调整项目列表、协作记录文件夹及同文件夹内记录的顺序，项目顶层的记录也支持。
- 拖到条目的上半部或下半部，蓝色插入线表示放在它之前或之后。拖动展开的组或文件夹时，落在子项区域也能定位整组，插入线显示在整组边界。
- 选中条目后也可用 Ctrl+↑/↓ 调整顺序。

排序保留当前选择、详情和展开状态；重命名或修改内容不会打乱已保存的顺序。未调整的列表沿用原有默认顺序，已调整列表中的新条目追加到同层末尾。保存失败时显示错误并保留原顺序。

重点文件夹继续置顶，重点与普通文件夹分别排序。搜索协作记录时暂不允许排序，清空搜索后恢复。工具或记录的跨组移动继续使用右键菜单。

## 数据与升级

数据库继续使用 schema v6，从 v2.3.2 升级无需结构迁移。排序不修改条目内容、归属或内容时间戳，并保留 v2.3.2 的树折叠与搜索无障碍缓存修复。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.4.0-windows-x64.zip` 完整解压运行；附件同时提供 `.zip.sha256` 校验文件。安装前请结束运行中的工具命令和关机倒计时。
