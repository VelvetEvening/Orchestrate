# v3.6.2 项目记录仅标题保存

- 项目中的协作记录只需填写标题即可保存为新记录，摘要和正文均可留空，之后可随时补充。
- 已有记录也可以清空摘要和正文后保存，保留记录身份、创建时间和文件夹归属。
- 标题去掉首尾空白后不能为空。移除“待填写正文”提示，保存状态正确显示“未保存 · Ctrl+S”或“已保存”。
- Ctrl+S 保存后继续编辑，离开页面时仍可选择保存、放弃修改或继续编辑。

数据库保持 schema v9，无需迁移。
