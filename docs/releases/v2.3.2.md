# Orchestrate v2.3.2

修复收起自动化工具组时可能出现的无响应及内存暴涨，建议 v2.3.1 用户更新。

## 工具组折叠稳定性

Windows 无障碍接口读取工具树后，收起工具组可能使 Qt 的节点缓存仍指向折叠前的行。后续界面读取会循环访问错误节点，导致主窗口卡住并消耗大量内存。

本版在折叠和展开时立即同步无障碍节点缓存。自动化工具组和协作记录文件夹共用这项修复，协作记录搜索也会同步更新可见节点映射，继续保留无障碍支持。

## 数据与升级

数据库继续使用 schema v6，从 v2.3.1 升级无需结构迁移。项目、日记、协作记录、工具注册、刷新偏好及工具自身状态继续保留。

可在“设置 → 版本与更新”检查并安装，或下载 `Orchestrate-v2.3.2-windows-x64.zip` 完整解压运行；附件同时提供 `.zip.sha256` 校验文件。安装前请结束运行中的工具命令和关机倒计时。
