Orchestrate @VERSION@ — Windows x64 便携版

使用方法
1. 完整解压 ZIP 到当前用户可写的文件夹。
2. 双击 Orchestrate.exe。无需安装 Qt、Qt Creator、MinGW 或 Python。
3. 保留 DLL、插件目录和 tools 目录的相对位置，不要只复制 EXE。

运行环境
Windows 10 1809 或更新版本的 64 位系统；建议使用仍受支持的 Windows 版本。
内置定时关机工具使用 Windows PowerShell 与任务计划程序。
SSH 工具需要本机 OpenSSH 客户端及已配置的免交互登录；外部工具需要自己的依赖。
WSL 工具需要已安装并初始化的 WSL 发行版及 Linux 工具依赖，通过 wsl.exe 原生调用，无需 PowerShell 包装。
“注册远程工具”提供 SSH/WSL 两种入口；SSH 默认列表只展示 ~/.ssh/config 直接声明的别名。
注册窗口支持选择或填写用户，成功后保存实际用户名；这里不会创建系统或服务器账号。
内置定时关机仅展示开启、关闭、设置弹窗时间、设置弹窗持续时间四条命令。
v2.0.0 支持从工具状态读取动态下拉选项、有效当前选择及表单顶部只读信息。
使用状态的表单打开时异步刷新，失败可重试；刷新保留有效选择，运行前验证必填项与选项。
工具须自行公开不含凭据的选项，并在执行时再次核验账号、环境与权限。
v2.1.0 精简工具页：介绍通过悬停查看，命令改为单行，连接来源只显示 SSH/WSL。
右键左侧工具，选择“查看工具信息”查看并复制主机、用户与路径。v2.1.1 恢复“当前状态”右上角的“刷新状态”按钮，右键刷新入口继续保留。
v2.1.2 修复状态读取未完成时关闭命令参数或 SSH/WSL 注册窗口可能导致的崩溃。
v2.2.0 支持右键项目切换“进行中／已完结”，默认进行中；右侧项目大纲与设置保留。
“工作记录”更名为“协作记录”，可按文件夹整理 AI 任务说明和提示词。文件夹支持新建、重命名、展开和收起。
选中文件夹后添加记录，或拖动记录到其他文件夹／项目顶层；删除文件夹会保留记录并移回顶层。
搜索支持标题、摘要和文件夹名称；搜索时展开匹配内容，清空搜索恢复原来的展开状态。
协作记录包含标题、摘要和正文，摘要由用户独立填写，可留空。v3.5.5 起打开即可编辑，标题同行右侧切换“摘要／正文”。
Ctrl+S 或底部“保存”一起保存三个字段，保存后继续编辑。正文默认 20pt、摘要 24pt，Ctrl＋滚轮分别调整并记住字号。
选中内容后可直接复制；返回、切换模块、关闭内容或窗口时提示处理未保存修改，保存失败保留草稿并留在记录页。
启动至少三分钟后异步检查更新，每 24 小时最多自动检查一次；设置入口和托盘显示更新提示，同一版本最多自动通知一次。
自动检查可关闭，不自动下载安装；检查失败不会连续重试。更新说明完整显示并支持滚动与复制。
v2.3.1 支持右键协作记录文件夹“标记重点并置顶”，显示金色五角星；再次右键可“取消重点标记”。
多个重点文件夹支持手动调序，未调序时按名称排序；标记随数据保存，重命名、切换项目和重启后保留。
v2.3.2 修复收起工具组后 Windows 无障碍接口可能循环读取旧节点、导致无响应与内存暴涨的问题。
工具组及协作记录文件夹在折叠、展开或搜索改变可见节点时及时同步缓存，继续保留无障碍支持。

v3.0.0 新增剪贴板工作区：支持文本、图片、网页富文本和文件路径，监听默认关闭，可随时开关。
带星标的“历史”接收新复制内容；可创建标签页及文件夹，拖动归类、调序，搜索固定在当前标签页。
双击条目复制并收起 Orchestrate，随后自行 Ctrl+V；文件条目保存路径，不保存文件本体。
默认 500 条上限仅约束“历史”顶层自动记录，从当前列表底部优先清理；调序会改变清理先后。
手动新建、编辑保存和移动归类过的内容保留；正在编辑的条目临时跳过，失败保留草稿，取消后解除临时保护。
删除文件夹或标签页保留内容；删除具体条目需确认。单条内容上限 16 MiB，图片上限 3200 万像素。
工具与协作记录也可直接拖入其他分类，顺序随数据保存。剪贴板空闲时不轮询，不增加日常滚动备份。
v3.0.0 更新目录替换遇到短时占用时最多尝试五次、间隔 500 毫秒；持续失败保留原有回滚行为。

v3.3.0 项目 Git 历史
“Git 历史”替换原项目大纲，支持本地 Windows、WSL 和 SSH 目录。对应环境须已安装 Git 并可从 PATH 调用。
历史窗口提供提交图、独立的分支／标签筛选、分页和查找；双击提交或按 Enter 查看说明、变更文件和 Diff。
分支对比通过所选远端实时查询完整分支，按同名分支的提交编号比较；不拉取代码、不建立仓库缓存。
查询失败时保留上次成功内容；成功时只显示读取状态。远端查询需要目标环境已有的网络和免交互认证。
双击项目会打开本地或 WSL 目录；SSH 项目显示主机、用户和路径并提供复制。

数据与升级
v3.1.0 为日记、提醒、大纲和协作记录预览加入离线公式排版，支持 \(…\)、\[…\]、$…$、$$…$$。
编辑、保存和复制保留公式原文。OrchestrateMath.exe 按需运行，完成后退出；请保留该文件。
不支持或过于复杂的公式保留原文。公式预览无需联网或安装 TeX；当前数据库为 schema v8。

首次运行在程序旁创建 data/orchestrate.sqlite3；工具状态在 tools/<工具>/state/。
升级或备份前，从托盘菜单选择“退出 Orchestrate”，再备份整个 data 目录和工具 state 目录。
v1.1.0 起可在“设置 → 版本与更新”检查 GitHub 正式 Release，下载、校验并安装更新。
安装前先结束运行中的工具及关机倒计时。v1.1.2 起安装时自动暂停本目录相关计划任务，结束后恢复原状态。
从 v1.1.0/v1.1.1 升级本版时仍由旧更新器执行：需手动暂停相关任务，升级后手动重新启用一次。
自动更新需要程序上级目录可写；保留个人数据、配置及程序路径，更新过程中在旁边临时保存完整旧版备份。
替换失败或新版未完成启动会恢复旧版。更新结果与备份位置在设置页显示。
v1.1.3 修复更新重启后只有后台进程、主窗口无法唤起的问题；兼容旧更新器的隐藏启动参数。
新版启动确认同时检查主窗口实际可见；更新器以正常窗口方式启动应用，托盘和快捷键可恢复原生窗口。
新版确认启动且任务恢复完成后，自动删除下载 ZIP、解压文件和更新临时目录；同时清理本次旧版完整备份；失败或任务恢复未完成则保留恢复材料。
启动时补清旧更新器留下的成功残留；清理遇到占用时下次启动重试，失败更新及任务恢复材料保留。
v1.0.0 首次升级需手动：新版解压到临时目录，复制旧 data、各工具 state 和个人配置，放回原路径。
本版升级至 schema v8；升级前先生成 data/backups/ 一致快照，迁移失败会回滚。
原项目目录默认保留为本地绑定；旧项目大纲及其专用偏好直接移除，不转换为协作记录。
原日记、提醒、项目、协作记录、文件夹和剪贴板内容保留。回退 v3.2.2 时须同时恢复 schema v7 数据库备份。
从 v2.4.1 或更早版本升级时，也会建立 v3.0.0 引入的剪贴板表。
从 schema v5 及更早版本升级时，已有文件夹默认未标记重点；已有重点标记、协作记录标题、摘要、正文、创建／更新时间、文件夹归属和项目状态保留。
从 schema v4 及更早版本升级时，旧协作记录的新增摘要留空，可自行填写。
使用 options_state_key 或 readonly 的工具声明需要 v2.0.0 或更新版本；旧版工具的静态选项继续兼容。
旧 SSH 注册继续沿用原配置用户；新注册保存明确用户名，确认新条目可用后可移除旧条目。
数据库迁移前的快照在 data/backups/；手动降级时同时恢复旧程序和数据库备份，不能只替换旧 EXE。
本包不包含个人数据库、工具状态、凭证或开机启动配置。
v1.1.1 起不同程序目录的开机自启开关独立，同目录更新保留设置。
升级保留指向当前程序的旧启动项；首次操作开关时迁移并保留 Windows 禁用状态。
移动前在旧目录关闭自启，移动后在新目录重新开启；其他目录的启动项不会自动清理。
旧版本仍使用共享启动项，验证两份程序隔离前请将两份都升级至 v1.1.1。

窗口和后台
关闭主窗口默认驻留托盘，Alt+X 可唤起；托盘菜单可完全退出。
开机自动启动默认关闭，在“设置 → 运行与托盘”中开启。
Alt+X 和定时关机计划任务仍是系统共享资源，本版隔离范围为开机自启。
