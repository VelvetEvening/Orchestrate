# Git 历史窗口

- Mode: Operate / Read。
- 沿用 DESIGN.md 的 Windows 原生灰白与雾蓝界面，不建立新的视觉体系。
- 主任务：回顾项目提交及具体文件变化；按名称与提交编号比较仓库分支。
- 构图已由 v3.3.0 设计确定：独立非模态窗口，顶部环境信息，提交历史／分支对比双页签；历史页主体仅保留提交图与列表，分支和标签各用独立下拉框。双击提交或按 Enter 才打开说明、文件和 Diff；每个历史窗口复用一个详情窗口。单击不会改变已打开的详情。
- 列表选择、焦点、按钮和表单复用原生 Qt 及现有主题；Git 图使用有限语义色，Diff 使用现有成功／危险配色，背景保持白色。
- 默认 1180×800，最小 780×540；保留表格水平滚动、文件长名提示和正文滚动。查找定位提交，不删掉图中必要的中间行。
- 加载、空仓库、普通目录、无远端、错误、失败保留上次结果和读取取消均为明确状态。
- 状态只说明读取成功、进行中或失败，不显示加载数量和时间。分页按钮仅在仍有历史时出现。
- 检查采用离屏合成数据及已授权的原生窗口；真实 WSL／SSH 认证依赖目标环境。
